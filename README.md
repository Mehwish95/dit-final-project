## 📌 Project Overview

**NovaTech** is a front-end website project for a fictional digital agency. It presents a polished online presence with a bold hero section, company introduction, service cards, image gallery, contact information, and footer navigation.

The project focuses on a clear layout, consistent visual styling, simple navigation structure, and responsive page layouts for different screen sizes.

> **Project type:** Front-end website  
> **Primary technologies:** HTML5 and CSS3  
> **JavaScript:** A `script.js` file is included in the project; no JavaScript functionality is currently implemented in it.

## ✨ Features

- **Modern hero section** with prominent headline and call-to-action links.
- **About section** introducing the agency and highlighting its values.
- **Services section** featuring six digital service categories.
- **Image gallery** with visual content for the agency theme.
- **Contact section** with sample contact details and a front-end form layout.
- **Responsive CSS layouts** with breakpoints for tablet and mobile screen widths.
- **Interactive visual states** including hover transitions, button effects, and smooth scrolling.
- **Reusable styling** through shared containers, buttons, grids, and section styles.

## ⚙️ Getting Started

No package manager, build tool, or framework is required to run the current project.

### 1. Download or clone the project

```bash
git clone <your-repository-url>
```

Alternatively, download the ZIP file and extract it to your computer.

### 2. Open the project folder

```bash
cd dit-final-project-main
```

### 3. Run the website

Open `index.html` directly in your web browser.

For a smoother development workflow, you can use the **Live Server** extension in Visual Studio Code:

1. Open the project folder in VS Code.
2. Install the Live Server extension if it is not already installed.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

The website should open in your default browser.

## 🎨 Customization

You can adapt the website to your own brand or project.

### Change website content

Edit `index.html` to update:

- Brand name and headings
- About and services descriptions
- Contact information
- Footer links and copyright text
- Image sources and alternative text

### Change the design

Edit `style.css` to customize:

- Brand colors and backgrounds
- Fonts and typography
- Spacing, sizing, and section layouts
- Card styles, shadows, and hover effects
- Responsive breakpoints

The primary accent color used throughout the current design is `#4f46e5` (indigo).

### Add JavaScript functionality

The `script.js` file is currently empty and is not yet connected to `index.html`. To add interactive behavior:

1. Implement the required JavaScript in `script.js`.
2. Add a script reference before the closing `</body>` tag in `index.html`, for example:

```html
<script src="script.js"></script>
```

3. Test the behavior in your browser, including on mobile screen sizes.

## ⚠️ Current Scope & Notes

This repository currently contains a **front-end presentation**. Keep the following limitations in mind:

- The contact form is a visual HTML form only; no backend or email delivery service is configured.
- The social media links are placeholders (`#`) and need real profile URLs.
- The displayed address, email, and phone number are sample content and should be replaced before publishing.
- The mobile menu icon is present, but menu-toggle behavior has not been implemented in JavaScript.
- Images are loaded from Unsplash URLs and therefore require an internet connection.
- No database, authentication system, API, or server-side application is included.
